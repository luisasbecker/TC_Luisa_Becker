# Marca Pipeline Bucal

`app_icon.png` é uma marca original gerada para este projeto em 29/10/2026: contorno oral acompanhado de quatro cantos de enquadramento, sobre vinho terroso, com apoio rosé e marfim. Não contém fotografia clínica nem afirmação diagnóstica.

A arte é rasterizada; não é um componente vetorial nativo do Figma. A identidade cromática da interface permanece definida pelos valores exatos de `design/tokens`, extraídos do SVG fornecido pela autora. A arte do ícone possui pequenas variações de tom próprias da geração.

O aplicativo usa a cópia em `mobile/assets/branding/app_icon.png`. Os launchers iOS e Android são derivados desta mesma fonte, sem transparência, e respeitam os tamanhos dos catálogos nativos existentes.

Para reproduzir os tamanhos em macOS: `python3 design/branding/generate_launcher_icons.py`.
